# 🧶 Crochetly Readme

Crochetly is a growing, human-friendly knowledge base for crochet stitches,
techniques, terminology, and best practices.

Its goal is to make crochet knowledge easier to find, easier to understand,
and easier to learn — whether you’re a beginner picking up a hook for the first
time or an experienced crocheter looking up a specific technique.

---

## What Crochetly Is

Crochetly focuses on **clear, structured reference content**, including:

- Stitch and technique explanations
- Common abbreviations and aliases
- Step-by-step written instructions
- Troubleshooting tips
- Fabric properties and use cases
- Cross-references and learning paths

Content is written to be:
- Beginner-accessible
- Technically accurate
- Consistent in structure
- Easy to expand over time

---

## What Crochetly Is Not

- A pattern marketplace
- A finished encyclopedia (it’s intentionally evolving)
- An automated content generator

Crochetly values **quality, clarity, and usefulness over volume**.

---

## Content Structure

Most reference content follows a standard template that includes:
- Clear definitions
- Instructions
- Variations
- Common mistakes
- Applications
- Related stitches and techniques

This consistency helps readers quickly understand new concepts and navigate
between related topics.

---

## Agents & Workflow

Crochetly uses **human-guided assistive agents** to help with:
- Drafting new content
- Editing and refining explanations
- Maintaining consistent structure
- Documenting workflows

Agents do not run autonomously and do not publish content automatically.
Humans make all final decisions.

See [`agents.md`](agents.md) for details.
