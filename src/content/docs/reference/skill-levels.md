title: Skill levels
description: Reference for the standard 4-level skill rating system used in crochet and knitting patterns, covering what techniques belong at each level and how to rate your own patterns.

Patterns often include a skill level so makers can choose projects that match their experience. The [Craft Yarn Council](https://www.craftyarncouncil.com/standards) defines four standard levels. Use this guide to rate your own patterns and to know what to expect from a pattern at each level.

## What are the four skill levels?

The standard system uses four levels: Beginner, Easy, Intermediate, and Experienced. Each level builds on the skills from the level before it.

### Beginner (Level 1)

A beginner pattern uses basic stitches with minimal shaping and simple finishing. The maker follows a single stitch pattern throughout with no complex color changes or techniques.

**Typical skills:**
- Basic stitches: knit, purl, single crochet, double crochet
- Simple increases and decreases (k2tog, ssk, sc2tog)
- Working flat in rows or in the round
- Simple finishing: bind off, weave ends, seam straight edges
- No color changes or simple stripes

**Example patterns:** Basic scarf, washcloth, simple hat, granny square

### Easy (Level 2)

An easy pattern introduces simple color changes, basic stitch pattern variations, and straightforward shaping. The maker follows a repeating pattern with minimal counting.

**Typical skills:**
- All beginner techniques
- Basic color changes (stripes)
- Simple stitch pattern combinations (ribbing, seed stitch, moss stitch)
- Basic shaping (armholes, necklines)
- Simple buttonholes
- Working from a basic chart

**Example patterns:** Striped blanket, simple sweater with minimal shaping, basic mittens

### Intermediate (Level 3)

An intermediate pattern uses more complex stitch patterns, techniques, and shaping. The maker follows multiple instructions at once and manages several stitch pattern elements simultaneously.

**Typical skills:**
- All beginner and easy techniques
- Stranded colorwork (fair isle, simple stranded)
- Cables and basic lace
- More complex shaping (set-in sleeves, darts)
- Multiple stitch pattern elements in one project
- Reading complex charts
- Buttonholes, zipper installation

**Example patterns:** Colorwork yoke sweater, cabled cardigan, lace shawl, fitted garment with shaping

### Experienced (Level 4)

An experienced pattern demands advanced techniques, precise finishing, and the ability to manage complex shaping alongside intricate stitch patterns. The maker adjusts techniques as they work.

**Typical skills:**
- All previous level skills
- Complex colorwork (intarsia, advanced stranded, mosaic)
- Complex lace with multiple stitch patterns
- Steeking
- Short rows and three-dimensional shaping
- Knitting in multiple directions
- Advanced finishing and tailoring
- Combining multiple advanced techniques in one project

**Example patterns:** Steeked colorwork cardigan, complex fitted garment, heirloom lace, intarsia sweater

## How do I rate my pattern?

Consider the most difficult technique the maker needs to execute, not the average difficulty. A pattern with mostly knits but one section of complex stranded colorwork is an intermediate pattern, not a beginner pattern.

- Start by listing every technique used in the pattern
- Find the most advanced technique on the list
- Match it to the level descriptions above
- Add a note in the pattern explaining which skills are required

If you are unsure, ask your tech editor or test knitters what level they would assign.

## Do the skill level symbols matter?

Yes. The CYC skill level symbols (a four-segment bar with the active level shaded) are recognized across the industry. Publishers, yarn companies, and pattern databases use them to help makers filter patterns. Use the official symbols in your patterns if you plan to publish or distribute them widely.

## Where does the skill level go in a pattern?

Place the skill level at the top of the pattern, near the title and difficulty rating. Most makers check this before reading anything else. Include it in your pattern preview or shop listing so makers can self-select.
