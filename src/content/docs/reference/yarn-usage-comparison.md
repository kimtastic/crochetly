Knitting typically uses less yarn than crochet for the same project size. This page breaks down the difference so you can plan your yarn purchases, substitute patterns between crafts, and avoid running short.

## Why does crochet use more yarn than knitting?

Crochet stitches are taller and have more structure than knit stitches. Each crochet stitch contains more yarn than a comparable knit stitch. The difference is most noticeable in taller stitches like double crochet and treble crochet.

As a general rule, crochet uses about 25% to 30% more yarn than knitting for the same project.

## What factors affect yardage?

Beyond the basic craft difference, several factors influence how much yarn you will need.

**Stitch pattern:** Textured stitches use more yarn. Crochet post stitches, cables in knitting, and dense stitch patterns all increase yardage. Looser openwork patterns use less.

**Tension:** Tight tension uses more yarn per stitch. Loose tension uses less. Your personal gauge can shift yardage by 10% or more.

**Project modifications:** Adding a border, increasing length, or making a wider version increases yardage in both crafts.

**Fiber type:** Some fibers (like cotton) have less stretch and may require different yardage than wool for the same project. This applies equally to both crafts.

## How do I estimate yardage when converting between crafts?

When converting a pattern from knitting to crochet, add 25% to 30% to the yardage. When converting from crochet to knitting, subtract about 25%.

**Example:** A knitting pattern calls for 300 yards of worsted weight yarn. For crochet, buy 375 to 390 yards.

**Example:** A crochet pattern calls for 500 yards of DK weight yarn. For knitting, 375 yards should be enough.

These are estimates. Swatch first and buy an extra skein if you are unsure. The [choosing yarn](/reference/choosing-yarn/) guide has more details on estimating yarn needs for both crafts.
