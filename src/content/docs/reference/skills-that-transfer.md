---
title: Skills that transfer between crochet and knitting
description: A guide to the skills, knowledge, and techniques that carry over between crochet and knitting, helping you learn the second craft faster
---

If you already know one craft, you already know more than you think about the other. Many skills transfer directly between crochet and knitting. This page covers what carries over and what does not.

## Yarn knowledge

Yarn is yarn, regardless of the craft. Understanding yarn weights, fiber types, yardage, and dye lots applies equally to crochet and knitting. The [choosing yarn](/reference/choosing-yarn/) guide covers everything you need to know about selecting yarn for any project.

## Tension and gauge

Tension and gauge work the same way in both crafts. You make a swatch, measure stitches per inch, and adjust your hook or needle size accordingly. The [gauge and tension](/terms/gauge-and-tension/) page explains the process, and it applies to both crafts without modification.

**One difference:** crochet swatches are often larger than knitting swatches because crochet stitches are taller. Make sure to swatch the same stitch pattern you will use in your project.

## Reading patterns

Crochet and knitting patterns use the same structure:
- Materials list
- Gauge information
- Abbreviations key
- Written instructions with repeats and brackets
- Finishing instructions

If you can read a knitting pattern, you can read a crochet pattern. You just need to learn the different abbreviations. The [crochet abbreviations](/abbreviations/crochet/abbreviations-us/) and [knitting abbreviations](/abbreviations/knitting/abbreviations-us/) pages cover both systems.

## Finishing techniques

Weaving ends, blocking, and seaming work the same way in both crafts. Blocking relaxes the fibers and evens out stitches. Weaving ends secures them so they do not come loose. Seaming joins pieces together.

The [blocking](/terms/blocking/) page covers blocking techniques for both crafts.

## Fixing mistakes

Frogging (ripping out your work) works the same way in crochet and knitting. You pull the yarn and start over. Lifelines work in both crafts too, though they are less common in crochet because there is only one active loop.

**One difference:** tinking (unraveling one stitch at a time) is easier in knitting. In crochet, you undo the last stitch by pulling the loop out of the hook, which is simple but different from knitting tinking. The [troubleshooting](/reference/troubleshooting/) page covers both approaches.

## Abbreviations

The symbols are different, but the logic is the same. Both crafts use abbreviated forms of common operation names. If you know how to look up a knitting abbreviation, you know how to look up a crochet abbreviation.

## Project planning

Estimating yarn needs, substituting yarn weights, and planning project dimensions work the same way in both crafts. The key difference is that crochet uses more yarn than knitting for the same project size. The [yarn usage comparison](/reference/yarn-usage-comparison/) page has detailed estimates.

## What does not transfer

Some skills are specific to each craft.

**Crochet skills that do not apply to knitting:**
- Working into a foundation chain
- Keeping one live loop on the tool
- Post stitches for texture
- Working in the round with a single continuous loop

**Knitting skills that do not apply to crochet:**
- Managing multiple live stitches on a needle
- Reading stitch mount (which leg of the stitch to work into)
- Picking up dropped stitches
- Cable techniques without a cable needle
- Kitchener stitch / grafting
