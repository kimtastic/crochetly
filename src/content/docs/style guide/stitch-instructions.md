---
title: Stitch instructions
description: How to write row-by-row stitch instructions for crochet patterns using numbered lists, parentheses for stitch groups, asterisks for repeats, and stitch count formatting
---

Stitch instructions tell you how to create each stitch, step by step. They show how to guide the yarn and hook to form loops, yarn overs, and pulls through.


## How do I format stitch instructions?
Use a numbered list for row and round instructions. Use parentheses for stitch groups and asterisks for repeats.

**Example:**
```plaintext
Ch 20.
Row 1: Sc in 2nd ch from hook and in each ch across. Turn. (19 sc)
Row 2: Ch 1, sc in next 3 sts, inc in next st; repeat from * to end. Turn.
```

## How do I show stitch counts?
Place stitch counts in parentheses at the end of each row or round. This helps makers verify their work as they go.

## How do I explain special techniques?
If your pattern uses a non-standard technique, explain it in a dedicated section before the written instructions. Include step-by-step descriptions and photos if helpful.
