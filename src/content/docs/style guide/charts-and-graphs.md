---
title: Charts and graphs
description: Guidelines for creating clear, accurate knitting and crochet charts, including when to include written instructions, row numbering, symbol keys, reading direction, and verifying that charts match the finished sample
---

Charts can be a helpful addition to a written pattern, especially for complex stitch patterns, lace, and colorwork. But they work best as a supplement, not a replacement.

## When should you use a chart?

Charts are most useful for patterns where the stitch arrangement is easier to see visually than to describe row by row. Lace patterns, cable patterns, and stranded colorwork are good candidates. For simple stitch patterns (single crochet, stockinette, basic repeats), a chart is rarely needed.

Consider your audience. Many knitters and crocheters prefer written instructions and do not read charts. If you include a chart, always add a note at the start explaining how to read it.

## Should a chart replace written instructions?

No. Charts should always be accompanied by written row-by-row or round-by-round instructions. A significant portion of makers cannot or will not use a chart. Without written instructions, you exclude a large part of your audience.

The written version is the primary pattern. The chart is a visual supplement that helps makers who prefer that format.

## How should rows and rounds be numbered?

Number every row or round clearly on the chart. The numbering should match the written pattern exactly so makers can cross-reference between them.

Use the same style of numbers (Arabic numerals, no leading zeros) throughout. Place row numbers on the side where the row begins.

## What size should a chart be?

Large enough to read without squinting. If a maker needs to zoom in on a phone screen or hold a printed page close to their face, the chart is too small.

Test your chart at typical viewing sizes: on a phone screen, on a tablet, and printed on letter or A4 paper. Each stitch symbol should be clearly distinguishable from the ones next to it.

## How do you read a chart?

Charts are read from the bottom up, starting with row 1 at the bottom.

- **Right-side rows (flat knitting):** Read from right to left.
- **Wrong-side rows (flat knitting):** Read from left to right.
- **In the round:** Every round is read from right to left because there are no wrong-side rows.

Include this information in a short note near the chart so new chart readers know how to follow it.

## What should a chart key include?

Every symbol used in the chart must appear in the key with its meaning clearly stated. Do not assume the maker knows what a symbol means.

Chart symbols are not universal. Different designers and publishers use different symbols for the same stitch. The Craft Yarn Council publishes a list of standard chart symbols that is a good starting point, but there is no single authoritative standard.

If you use a non-standard symbol, explain it in the key and consider whether a more common alternative would work instead.

## How do you verify a chart is correct?

A chart with errors is more confusing than no chart at all. Before publishing, check the following:

- **Stitch counts match.** The number of stitches per row or round in the chart must match the written pattern exactly.
- **Numbering is consistent.** Row numbers, repeat markers, and section labels should match between the chart and the written instructions.
- **The chart produces the right fabric.** Work a test swatch from the chart alone, then compare it to the sample. If the swatch does not match, the chart or the sample description needs correction.

## How do crochet charts differ from knitting charts?

Crochet charts use international symbol notation, where each shape represents a specific stitch (a dot for a chain, a cross for a single crochet, a T shape for a double crochet). Unlike knitting charts, which use grid squares, crochet charts show the actual shape and path of each stitch.

Crochet charts are also read from the bottom up. Each row is read in the direction it is worked: right to left for right-handed makers, left to right for left-handed makers. Turning chains and foundation chains should be clearly marked.

Include a symbol key specific to the stitches used in the chart, and note whether the chart is written for right-handed or left-handed crocheters.
