title: Crochet for knitters
description: A knitter's guide to picking up a crochet hook, covering tools, basic stitches, terminology differences, and tips for cross-craft learners
---

If you already knit, you already understand yarn, tension, gauge, and pattern reading. Picking up a crochet hook is easier than starting from scratch. This guide covers what you need to know to begin.

## What tools do I need to start crocheting?

You already own most of what you need. Crochet requires fewer tools than knitting.

**New tools:**
- **Crochet hook** -- start with a 5 mm (US H-8) hook, the most common size
- **Hook set** (optional) -- a set of hooks from 2 mm to 6 mm covers most yarn weights

**Shared with knitting:**
- Yarn -- same yarn works for both crafts
- Tapestry needle -- for weaving ends
- Stitch markers -- for marking places and tracking rounds
- Scissors
- Measuring tape

The main difference: you only need one hook instead of two needles. Crochet has no stitch holders because you never hold live stitches -- each stitch is completed before you start the next one.

## Knitting terms vs crochet terms

| Knitting | Crochet | Notes |
|---|---|---|
| Cast on | Foundation chain | Crochet starts with a chain instead of casting on |
| Knit stitch | Single crochet | Both are the default basic stitch of each craft |
| Purl stitch | No direct equivalent | Crochet has no purl -- texture comes from post stitches |
| Yarn over | Yarn over | Same term, different meaning. In crochet you yarn over on almost every stitch. In knitting a yarn over is a deliberate increase |
| Bind off | Fasten off | Same concept -- securing the last stitch and weaving in the tail |
| Right side / Wrong side | Right side / Wrong side | Same concept, but crochet stitches are more uniform on both sides |
| Gauge / Tension | Gauge / Tension | Same concept, same swatching method |
| Dropped stitch | No equivalent | Crochet stitches cannot drop because only one loop is active at a time |

## What are the basic crochet stitches?

If you are new to crochet, [YouTube crochet tutorials](https://www.youtube.com/results?search_query=crochet+tutorials) provide clear, helpful guidance.

### Slip knot

1. Loop the yarn, insert the hook through the loop, and pull it through to make a loop on the hook.
2. Pull gently on both yarn ends to tighten the knot against the hook.

### Chain (ch)

1. Make a slip knot on your hook.
2. Yarn over, pull through the loop.
3. Repeat to desired length.

### Single crochet (sc)

1. Insert hook into stitch.
2. Yarn over, pull through (2 loops on hook).
3. Yarn over, pull through both loops.

### Double crochet (dc)

1. Yarn over.
2. Insert hook into stitch.
3. Yarn over, pull through (3 loops on hook).
4. Yarn over, pull through 2 loops.
5. Yarn over, pull through remaining 2 loops.

## What is different about crochet fabric?

Crochet fabric is denser and less drapey than knitting. It holds its shape better. This makes crochet ideal for bags, baskets, amigurumi, and structured garments.

Crochet stitches are taller than knit stitches. A single crochet row is roughly the height of a stockinette row. A double crochet row is about twice as tall. This means crochet projects work up faster than knitting with the same yarn weight.

One thing to watch: crochet uses more yarn than knitting for the same project. If a knitting pattern calls for 400 yards of worsted weight yarn, expect to use about 30% more for crochet.

## How do I read a crochet pattern?

Crochet patterns use the same structure as knitting patterns. The main difference is the abbreviations. See the [reading patterns](/reference/reading-patterns/) guide for a general overview. The [crochet abbreviations](/abbreviations/crochet/abbreviations-us/) page covers US terms, and the [UK abbreviations](/abbreviations/crochet/abbreviations-uk/) page covers UK terms.

## What yarn should I use?

The [choosing yarn](/reference/choosing-yarn/) guide applies to both crafts. Start with a smooth, light-colored, medium-weight yarn (worsted / category 4) so you can see your stitches clearly.
