Loom knitting uses different abbreviations than needle knitting because the technique is different. This guide covers the standard abbreviations used in loom knitting patterns.

**Source:** [Craft Yarn Council](https://www.craftyarncouncil.com/standards) loom knitting abbreviation standards

## What are the standard loom knitting abbreviations?

| Abbreviation | Description |
|---|---|
| AW | All worked (repeat across the row) |
| BO | Bind off |
| CO | Cast on |
| E-wrap | E-wrap cast on or e-wrap stitch |
| FL | Flat loom (single-sided loom) |
| G | Garter stitch (knit one row, purl one row on flat loom) |
| K | Knit stitch (flat loom, also called flat knit stitch) |
| K2tog | Knit two stitches together (decrease) |
| KK | Knit stitch (round loom, also called round knit stitch) |
| P | Purl stitch |
| P2tog | Purl two together (decrease) |
| Pw | Purl wrap |
| R | Round loom (circular or double-sided loom) |
| Rnd(s) | Round(s) |
| RS | Right side |
| Sl | Slip stitch |
| st(s) | Stitch(es) |
| U | U-wrap knit stitch |
| W | Wrap |
| WS | Wrong side |
| WY | Working yarn |
| yo | Yarn over |

## What is the difference between flat loom and round loom abbreviations?

Flat loom (FL) abbreviations apply to single-sided looms where you knit back and forth. Round loom (R) abbreviations apply to circular looms where you work in continuous rounds. Flat knit stitch (K) on a flat loom is different from round knit stitch (KK) on a round loom.

## How do I read loom knitting stitch patterns?

Loom knitting stitch patterns use the same format as needle knitting patterns. A typical instruction reads: "Knit 1, Purl 1 across the row" abbreviated as "K1, P1 AW." Check the pattern key for any special stitches the designer uses.

## How do loom knitting abbreviations differ from needle knitting?

The main difference is the knit stitch. In needle knitting, a knit stitch is always k. In loom knitting, k means flat knit on a flat loom and kk means round knit on a round loom. Purl stitches (p) work the same way regardless of loom type.
