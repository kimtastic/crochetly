**Knitting** is a needlework technique where you create fabric by interlocking loops of yarn or thread using two knitting needles. This page covers common knitting terms you will see in patterns.

**Sources:** [The Craft Yarn Council](https://www.craftyarncouncil.com/)

## Basic knitting terms

The table below covers essential knitting terms: knit, purl, cast on, bind off, and more. These are the building blocks of every pattern.

| Term                       | Abbreviation    | Meaning                                                                 |
|----------------------------|-----------------|-------------------------------------------------------------------------|
| **Beginning of Round**     | `BOR`           | The starting point of a round, often marked with a stitch marker.      |
| **Bind Off**               | `BO`            | Securing stitches to finish your work.                                  |
| **Blocking**               | -               | A finishing technique to shape and set the fabric.                      |
| **Cast On**                | `CO`            | Creating the foundation row of stitches onto the needle.                |
| **Changing Color**         | -               | Switching to a different yarn color at the start of a row or round.     |
| **Contrast Color**         | `CC`            | A secondary color used in a pattern.                                    |
| **Fastening Off**          | -               | Cutting the yarn and pulling it through the last stitch to secure your work. |
| **Gauge**                  | -               | The number of stitches and rows per inch; important for sizing.         |
| **Holding the Yarn**       | -               | The way you tension and guide yarn with your non-dominant hand.         |
| **Joining Yarn**           | -               | Attaching a new strand of yarn, often at the beginning of a new section or color. |
| **Knit**                   | `k`             | The most basic knitting stitch; insert the needle through the loop from front to back. |
| **Knit Two Together**      | `k2tog`         | A right-leaning decrease by knitting two stitches together.             |
| **Main Color**             | `MC`            | The primary color used in a pattern.                                    |
| **Make One**               | `M1`            | An increase by picking up the bar between two stitches and knitting it. |
| **Make One Left**          | `M1L`           | A left-leaning increase.                                                |
| **Make One Right**         | `M1R`           | A right-leaning increase.                                               |
| **Place Marker**           | `pm`            | Place a stitch marker to mark a section or pattern repeat.              |
| **Purl**                   | `p`             | The reverse of a knit stitch; insert the needle through the loop from back to front. |
| **Purl Two Together**      | `p2tog`         | A decrease by purling two stitches together.                            |
| **Repeat**                 | `rep`           | Do the previous instructions again.                                     |
| **Right Side**             | `RS`            | The intended front or visible side of your project.                     |
| **Round**                  | `rnd`           | A circle of stitches; common in hats, socks, and sweaters.             |
| **Slip Marker**            | `sm`            | Move the marker from one needle to the other as you work.              |
| **Slip Slip Knit**         | `ssk`           | A left-leaning decrease by slipping two stitches and knitting them together. |
| **Slip Stitch**            | `sl` or `sl st` | Passing a stitch from one needle to the other without working it.    |
| **Stitch**                 | `st`            | A general term for any individual loop on the needle.                   |
| **Swatch**                 | -               | A small sample made to check gauge and tension before starting a project. |
| **Total Stitches**         | `TS` or `sts`   | The total number of stitches currently on the needle.                   |
| **Weave In Ends**          | -               | Tucking and hiding yarn tails in your work for a neat finish.           |
| **Work Even**              | -               | Continue in pattern without increasing or decreasing.                   |
| **Working in Rounds**      | -               | Knitting in a circle using circular or double-pointed needles.          |
| **Working in Rows**        | -               | Knitting back and forth in rows, turning the work at the end of each row. |
| **Wrong Side**             | `WS`            | The back or reverse side of the project.                                |
| **Yarn Over**              | `yo`            | Wrapping the yarn over the needle to create an eyelet or increase.      |

## Common knitting stitch patterns

The table below covers frequently used knitting stitch patterns and techniques.

| Pattern Name       | Meaning                                                                 |
|--------------------|-------------------------------------------------------------------------|
| **Stockinette Stitch** | Alternating knit rows and purl rows; smooth on the front, bumpy on the back. |
| **Garter Stitch**   | Knit every row; creates a bumpy, reversible fabric.                     |
| **Ribbing**         | Alternating knit and purl stitches in the same row; creates stretchy fabric. |
| **Seed Stitch**     | Alternating knit and purl stitches, offset each row; creates a textured fabric. |
| **Cable**           | Crossing stitches over each other to create a twisted rope pattern.      |
| **Lace**            | Using yarn overs and decreases to create decorative holes and patterns.  |
| **Fair Isle**       | Working with multiple colors in the same row, carrying yarn across the back. |
| **Intarsia**        | Working with blocks of color using separate yarn bobbins.              |
